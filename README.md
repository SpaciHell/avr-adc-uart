# avr-adc-uart
ATmega328P первый учебный проект
Измерение напряжения на ATmega328P: потенциометр; АЦП; вольты; терминал. Написано на регистрах, без библиотек Arduino. Проверено в Proteus.
## Что делает программа:
1. Считывает данные с потенциометра при помощи АЦП.
2. Преобразует из формата АЦП в вольты
3. Выводит получившееся значение в консоль раз в 100 мс в формате "U = 2.50 V"
4. Можно взаимодействовать с консолью при помощи команд 's' и 'g'
## Схема
- PC0 (ADC0) — вольтметр(для проверки корректности значений)
- PC0 (ADC0) — потенциометр
- PD0/PD1 — Virtual Terminal, 9600 бод
     - TXD чипа (PD1) - RXD терминала
     - RXD чипа (PD0) - TXD терминала
- AVCC (18) +5 В
- ATmega328P, 16 МГц, CKSEL Fuses (1111)
## Команды
's' - остановить вывод в консоли
'g' - возобновить вывод в консоли
## Как устроено
1. Timer1 посредством прерываний поднимает флаг каждые 100мс, что значение пора отправлять в терминал. Режим СТС и делитель 256
2. АЦП используется для чтения значений с потенциометра с последующим преобразованием в вольты. Делитель частоты 128, опорное напряжение +5В
3. UART используется для отправки значений в терминал и считывания команд прерывания и возобновления вывода
4. Каждое значение усредняется по 8 измерениям для избежания колебаний
## Шаги проекта
| Папка | Что добавлено |
|---|---|
| step1 | мигание по прерыванию Timer1|
| step2 | счётчик по INT0, антидребезг на Timer1|
| step3 | вывод строки по UART раз в секунду|
| step4 | вывод числа в терминал (счётчик)|
| step5 | чтение АЦП с потенциометра|
| step6 | перевод АЦП в вольты|
| step7 | усреднение значений|
| step8 | команды s/g по прерыванию|
## Как запустить
1. Открыть проект в Arduino IDE. Нажать на галочку слева сверху, чтобы проверить, что всё компилируется.
   После удачной компиляции выполнить следующие действия: Нажать "скетч" - "экспорт бинарного файла"
2. Схема Proteus должна находиться в одной папке с файлом кода. Запустить Proteus обязательно от имени администратора, иначе не будут работать библиотеки.
   После появления схемы два раза щёлкнуть по микроконтроллеру и нажать на обзор "Program file", если до этого был экспортирован файл кода, то должно быть
   два hex файла. Стоит выбрать файл без "with_bootloader" в названии. После загрузки кода настроить все характеристики что указаны выше (там всё уже должно
   быть настроено, но проверить стоит). Запустить симуляцию
